Capabilities

(03) — How I can help

From a blank Figma file to a shipped release: discovery, information architecture, flows, high-fidelity interface, and the unglamorous edge cases — empty, error, offline, loading, and everything at 320px wide.

Token architecture, component APIs, contribution models and documentation that engineers actually open. I build the system and the culture that keeps it alive.

Choreography with a reason: easing curves tied to physics, transitions that preserve context, and prototypes in code so the feel is agreed before a sprint starts. Always with a reduced-motion path.

GSAP, Three.js, GLSL and modern CSS. I hand over branches, not just files — production-ready front-end for the moments where the marketing site has to carry the story.

Interviews, usability testing, and honest metrics. I would rather kill a beautiful screen early than defend it for six months in a roadmap review.
